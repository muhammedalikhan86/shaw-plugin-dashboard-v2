What changed on the test site

This note lists what has changed on the Shaw Portal test site since the third test release of 27-11-2026. Changes to how the screens work are listed first, then changes to how they look.

How it works How it looks

How it works

Functional changes

Test site only

  1. Testers can now act as each of the test people and see exactly what that person would see:
    • national.seat: the national view.
    • vic.sm, nsw.sm and qld.sm: a State Manager in each of those states.
    • hannah.ilves.da, rowan.achebe.da and briony.glenarvon.da: one Dealer's Assistant in each state.
    Anyone who is not a tester is still kept out of the test site.

Compliance Dashboard

  1. "Open as sent" now greets the client with "Dear" followed by the client's salutation, exactly as the sent notice did.

How it looks

Design changes

Whole portal

  1. The page no longer squashes when the browser window is made small. Below 1280 by 720 it keeps its size and can be scrolled instead.

Compliance Dashboard

  1. In the Field library window, the column headings now stay fixed at the top while the list scrolls. The window is wider, and the "Used by" column is twice as wide.

Switched off or deferred

  • Portfolio Services: electronic signing through Annature is switched off on the test site again while IT checks the testers' mailbox setting.
